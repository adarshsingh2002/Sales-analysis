# 📊 US Sales Analysis Dashboard (Choropleth Map)

## 🔍 Overview

This project analyzes **state-wise sales performance** across the United States using data visualization techniques. A choropleth map is used to highlight regional sales distribution and identify high-performing states.

---

## 🎯 Objective

* Analyze revenue distribution across different states
* Identify top-performing regions
* Enable data-driven decision-making using visual insights

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* Plotly (Choropleth Map Visualization)

---

## 📁 Dataset

The dataset contains:

* `state` → US state codes
* `revenue` → Sales revenue data

---

## ⚙️ Key Steps Performed

1. Data aggregation using groupby (state-level revenue)
2. Data transformation (converted revenue into millions)
3. Built an interactive choropleth map using Plotly
4. Customized visualization with color scaling and hover insights

---

## 📊 Key Insights

* Identified top 5 revenue-generating states
* Observed regional sales trends across the US
* Highlighted underperforming states for potential improvement

---

## 📈 Output

* Interactive map displaying revenue distribution
* Clear visual comparison of sales performance by state
